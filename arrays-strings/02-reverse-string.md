# Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

We use two pointers, one at the beginning and one at the end
of the string. We swap the characters at both positions and
move the pointers towards the center.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

The string is reversed in-place without using another string.
